# Site de Portfólio - Juan Pablo | Desenvolvedor Web & Soluções Digitais

Um site moderno e responsivo que apresenta serviços de desenvolvimento web, automação e soluções com inteligência artificial. 

## 🎨 Características

* **Design moderno** com animações e efeitos visuais
* **Apresentação de serviços**: Landing Pages, Sites Profissionais, Sistemas de Atendimento 24h, Automações e Soluções Personalizadas
* **Portfólio de projetos** com links para trabalhos realizados
* **Seção de tecnologias** utilizadas (HTML, CSS, JS, SQL, Node.js, IA, N8N)
* **Galeria visual** para demonstração de trabalhos
* **Depoimentos de clientes** em slider interativo
* **Processo de trabalho** documentado
* **Responsivo** e otimizado para mobile

## 🛠️ Tecnologias

HTML5 | CSS3 | JavaScript | Responsivo
